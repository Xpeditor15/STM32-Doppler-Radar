# EEEE2072: Electronics Systems Group Design Project
## Project Overview:
This repository contains the complete firmware source codes for the Electronic Systems Group Design Project. 
The objective of the project is to develop a system architecture capable of detecting the velocity of a moving object using the Doppler shift effect. 
It consists of a STM32 L476RG Nucleo microcontroller, which acquires and processes the output from a HB100 Doppler Radar Module. 
The calculated velocity is then displayed onto two 7-segment displays using the Xilinx XC2C64A CPLD as the LED driver. 

The project can be divided into the following stages:
1. #### Signal Conditioning
The output of the HB100 Doppler Radar Module is passed into a second-stage RC bandpass filter to isolate the desired frequencies and attenuate the high frequency noise generated by the Doppler radar module. The signal is subsequently passed into an amplifier, which boosts it to a maximum amplitude of 3.3V to safety interface with the microcontroller's ADC. 

2. #### Signal Acquisition and Processing
The STM32 acquires the conditioned signal using its ADC and comparators peripheral. Using Fast-Fourier Transform (FFT), the dominant frequency of the received signal is obtained and the velocity of the moving object is calculated in real time and displayed onto a LCD Keypad Shield. The calculated velocity is also transmitted to the CPLD using the RS-485 protocol. 

3. #### Signal Receiver and LED Display Driver
The transmitted serial data is receiver using 16x oversampling to ensure signal integrity and minimize effects of clock drift. The data is then converted into parallel data by implementing a shift register in the CPLD. The CPLD subsequently drives the LED displays with Active-Low logic, since the LED displays are common-anode. 

The complete source code for the STM32 can be found in the STM32 folder, along with the configuration .ioc file. The complete hardware description code for the Xilinx XC2C64A CPLD can be found in the XC2C64A folder, along with the necessary testbench simulation code.
